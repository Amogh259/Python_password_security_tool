# 🔐 CIPHERVAULT – Python Password Security Tool

**Create Smart. Verify Strong. Stay Secure.**

CIPHERVAULT is a Python-based password security tool that allows users to generate random passwords, validate passwords, and evaluate password strength.

## ✨ Features

- **Password Generator:** Generate random passwords using uppercase letters, lowercase letters, numbers, and special characters.
- **Password Validation:** Validate passwords based on predefined security requirements.
- **Password Strength Checker:** Evaluate password strength by checking length and character combinations.
- **Interactive Menu:** Simple menu-driven interface for easy navigation.
- **User-Friendly Output:** Clear instructions and feedback for users.

## 🛠️ Technologies Used

- Python 3
- Random Module
- Conditional Statements
- Loops
- String Manipulation
- Functions

## 📋 Requirements

- Python 3.x installed on your computer.
- Any Python IDE or code editor (VS Code, PyCharm, IDLE, etc.).

No external Python libraries are required if you are using the standard-library version of the project.

## 🚀 Installation & Setup

Follow these steps to run CIPHERVAULT on your computer.

**1. Clone the repository**

```bash
git clone https://github.com/Amogh259/Python_password_security_tool.git
```

**2. Navigate to the project directory**

```bash
cd Python_password_security_tool
```

**3. Run the Python program**

```bash
python password_security_tool.py
```

If your Python file has a different name, replace `password_security_tool.py` with your actual filename.

## 🔒 Password Security Criteria

The password strength checker evaluates passwords based on the following criteria:

- Minimum length of 8 characters.
- At least one uppercase letter.
- At least one lowercase letter.
- At least one digit.
- At least one special character.

## ⚠️ Disclaimer

This project demonstrates basic password generation and strength evaluation and is not intended to replace professional password management or security solutions.

The standard Python `random` module is not cryptographically secure. For real-world password generation, use Python's `secrets` module.
